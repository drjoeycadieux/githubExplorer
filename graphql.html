GitHub GraphQL API

GraphQL Explorer

Query GitHub directly from your browser. Requests go straight to api.github.com/graphql using your own personal access token; this site never proxies or stores it on a server.

Personal access token

GitHub GraphQL requires authentication. The token is kept in this browser's local storage and shared with the main explorer.

No token

A token is required. Save a read-only token above to start the GraphQL IDE. Do not use a token with write access here.

Query editor

Press Ctrl + Enter to run a query.

Fewer requests

A single GraphQL query can return a profile, its repositories and follower counts instead of several REST calls.

Point-based limits

GitHub GraphQL uses point-based rate limits rather than request counts. Query rateLimit to inspect the current budget.

No shared secret

This page has no backend and no embedded token. Every visitor authenticates with their own token.
